# Changelog

## 1.1 — 2026-10-27

- Provide a standalone command-line workflow for profiling supplied gene-family members and comparing samples.
- Expose raw positional, row-normalized positional and position-independent frequency profiles, with explicit count filters and optional record selection.
- Export matrices, clustering results, input checksums, parameters and dependency versions in each run manifest.
- Provide an offline interactive heatmap for positional profiles, a deterministic synthetic example and regression tests.
- Check invalid inputs, zero profiles, requested cluster counts and existing output directories.
- Use version 1.1 consistently in the command-line version output, run manifest and documentation.

## 1.0

Original gene-family molecular profiling software. Version 1.1 retains its family-level profiling purpose and provides the documented command-line distribution above.
